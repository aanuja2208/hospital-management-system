# Hospital Operations & Decision Analytics - Power BI Guide

This document outlines how to build the operational healthcare dashboard in Power BI using the data generated by `generate_powerbi_data.py`.

## 1. Data Model (Star Schema)
Import the 5 generated CSV files into Power BI Desktop. In the **Model View**, establish the following relationships:
- `FactAppointments[DepartmentID]` -> `DimDepartment[DepartmentID]` (Many-to-One)
- `FactAppointments[DoctorID]` -> `DimDoctor[DoctorID]` (Many-to-One)
- `FactAppointments[PatientID]` -> `DimPatient[PatientID]` (Many-to-One)
- `FactAppointments[DateID]` -> `DimDate[DateID]` (Many-to-One)

## 2. DAX Measures
Create the following DAX measures in your `FactAppointments` table to drive the analytics:

```dax
Total Appointments = COUNTROWS(FactAppointments)

Completed Appointments = CALCULATE(COUNTROWS(FactAppointments), FactAppointments[Status] = "COMPLETED")

No-Shows = CALCULATE(COUNTROWS(FactAppointments), FactAppointments[Status] = "NO_SHOW")

No-Show Rate % = DIVIDE([No-Shows], [Total Appointments], 0)

Completion Rate % = DIVIDE([Completed Appointments], [Total Appointments], 0)

Avg Wait Time (Mins) = AVERAGE(FactAppointments[WaitTimeMinutes])

Avg Lead Time (Days) = AVERAGE(FactAppointments[LeadTimeDays])

Doctor Utilization % = DIVIDE([Completed Appointments], MAX(DimDepartment[CapacityPerDay]), 0)
```

## 3. Dashboard Pages Structure

### Page 1: Executive Overview
- **Visuals:**
  - KPI Cards: Total Appointments, No-Show Rate %, Completion Rate %, Avg Wait Time
  - Line Chart: Total Appointments by `DimDate[Date]` (Trend analysis)
  - Donut Chart: Appointments by `DimDepartment[DepartmentName]`

### Page 2: Department and Doctor Performance
- **Visuals:**
  - Matrix Table: `DepartmentName` (Rows), `DoctorName` (Sub-rows) -> Values: Total Appointments, Completion Rate %, No-Show Rate %
  - Clustered Bar Chart: Doctor Utilization % by `DoctorName`

### Page 3: Patient Flow
- **Visuals:**
  - Funnel Chart: Booked -> Completed
  - Pie Chart: `IsNewPatient` (New vs Returning)
  - Scatter Plot: `LeadTimeDays` (X-axis) vs `No-Show Rate %` (Y-axis) (To show if booking further in advance increases no-show likelihood)

### Page 4: Operational Recommendations
- **Visuals:**
  - Table (Underutilized Doctors): Filter `Doctor Utilization % < 50%`
  - Table (High No-Show Risk Segments): Matrix of `DayOfWeek` vs `DepartmentName` with `No-Show Rate %` in Values (Use Conditional Formatting to highlight high rates > 20% in Red).
